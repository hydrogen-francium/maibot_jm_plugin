# JM 本子下载插件

JM 插件是一个给 MaiBot 使用的 JMComic 下载和以图搜本插件。安装后，你可以在聊天中搜索 JM 本子、下载指定章节、生成 PDF 或 AES 加密 ZIP，也可以发送图片反查对应的 JM 本子。

插件使用 MaiBot SDK v2，不依赖 AstrBot。默认以图搜本服务为 SoutuBot，通常不需要填写 API Key。

## 你可以用它做什么

- 使用 `/jm 车牌号` 下载单章节本子。
- 使用 `/jm 车牌号 章节号` 下载指定章节。
- 使用 `/jm 车牌号 起始-结束` 下载章节范围，例如 `/jm 123456 1-5`。
- 使用 `/jm 关键词` 搜索 JM 本子；使用 `/jm 关键词 页码` 翻页搜索。
- 在当前消息附带图片后发送 `/jm搜图`，进行以图搜本。
- 回复一条含图片的消息，再发送 `/jm搜图`，使用被回复消息中的图片搜索。
- 自动生成 PDF；也可以选择生成真正的 AES 加密 ZIP。

## 安装

1. 在 MaiBot WebUI 的插件页面安装本插件。
2. 安装完成后重启 MaiBot。
3. 在插件列表中找到“JM 本子下载插件”，确认插件已启用。
4. 打开插件配置页面，按下面的说明填写配置。
5. 保存配置，必要时重启 MaiBot 或重新加载插件。

插件 ID 是 `hydrogen-francium.jm_plugin`。仓库地址：<https://github.com/hydrogen-francium/maibot_jm_plugin>。

如果 WebUI 支持自动安装依赖，插件会根据 Manifest 自动安装 `aiohttp`、`Pillow`、`jmcomic` 和 `pyzipper`。其中 `pyzipper` 仅在启用加密 ZIP 时使用，但建议保留安装。

## 第一次配置

### 必填配置

通常只需要确认 NapCat 地址：

- **NapCat 地址**：默认是 `http://127.0.0.1:3000`。如果 NapCat 的 HTTP API 使用其他端口，请改成实际地址。
- NapCat 必须正在运行，并且已启用对应的 HTTP API，否则插件无法把 PDF 或 ZIP 发回聊天。

如果 MaiBot 和 NapCat 在同一台电脑上，通常不需要修改默认地址。NapCat 不在同一台电脑时，请填写 MaiBot 能访问的地址，并不要把 NapCat 管理接口直接暴露到公网。

### 下载目录

- **下载目录**留空：使用 MaiBot 为插件分配的数据目录，推荐新手使用此设置。
- 填写目录：只有在你明确知道目录权限和磁盘空间时才使用自定义路径。
- 临时图片、PDF、ZIP 和配置文件会放在插件运行目录中，任务结束后会自动清理。

### 权限设置

插件提供两层名单，分别控制群和用户：

- **群聊名单模式**：
  - `off`：不限制群聊。
  - `whitelist`：只允许群号列表中的群使用。
  - `blacklist`：禁止群号列表中的群使用。
- **用户名单模式**：
  - `off`：不限制用户。
  - `whitelist`：只允许 QQ 号列表中的用户使用。
  - `blacklist`：禁止 QQ 号列表中的用户使用。

名单填写 QQ 号或群号字符串，例如 `["123456789"]`。两层权限会同时生效；任意一层拒绝，命令就不会执行。用户名单同时适用于群聊和私聊。

### 以图搜本

默认 provider 是 **SoutuBot**，一般不需要 API Key。建议先保持默认值，只在服务地址确实不可访问时再检查网络、代理或 FlareSolverr 配置。

如果切换到 **SauceNAO**，需要填写你自己申请的 SauceNAO API Key。不要把 API Key 发到群里、截图、日志、Issue 或 Git 仓库中。

常用参数：

- **图片大小上限**：默认 10 MiB，超过限制的图片不会上传。
- **搜图超时**：默认 30 秒，超时后会自动进行一次有限重试。
- **最低相似度**：默认 40。调高会减少误匹配，但可能漏掉翻译标题。
- **候选结果上限**：插件会展示搜图候选，并依次尝试最相关的前三个结果。

## 命令用法

```text
/jm 123456
/jm 123456 2
/jm 123456 1-5
/jm 关键词
/jm 关键词 2
```

单章节本子可以直接使用 `/jm 车牌号`。多章节本子必须指定章节或章节范围，插件不会在没有确认的情况下默认下载全部章节。

章节范围支持以下形式：

```text
/jm 123456 1-5
/jm 123456 -5
/jm 123456 3-
```

图片搜索：

```text
[当前消息附带图片] /jm搜图
[回复一条含图片的消息] /jm搜图
```

搜图命令只读取当前消息附带的图片，或当前消息明确回复的那条消息中的图片。插件不会从群聊最近消息中随意挑选图片，避免搜错内容。引用消息正文里即使出现 `/jm搜图`，也不会被当作当前消息的命令。

## 输出文件

对外发送的文件名使用 JM 车牌号，避免完整标题过长导致 Windows 或 QQ 上传失败：

```text
JM123456.pdf
JM123456_02.pdf
JM123456_01-05.pdf
```

启用加密 ZIP 后，文件可能使用你在“伪装扩展名”中填写的扩展名发送，例如 `JM123456.dat`。这只是文件名伪装，内部仍然是 AES ZIP；收到文件后可以改回 `.zip` 再解压。

加密 ZIP 的密码是文件名主体，不含扩展名。例如：

```text
文件名：JM123456.dat
密码：JM123456
```

加密 ZIP 需要 `pyzipper`。如果依赖不可用，插件会提示配置或安装依赖，不会把普通未加密 ZIP 冒充成加密 ZIP。

## 常见问题

### 插件没有反应

确认插件已在 WebUI 中启用，并且重启 MaiBot。再确认命令是单独发送的 `/jm ...` 或 `/jm搜图`，不要把命令写在普通长文本或引用内容里。

### 下载失败

先确认车牌号正确、JMComic 网络可访问，并检查 JM 代理配置。多章节本子需要明确填写章节。下载过程中会限制 PDF 最大页数，默认上限为 500 页。

### 搜图失败

确认当前消息确实附带图片，或者引用的消息确实包含图片。检查图片大小是否超过上限，以及 SoutuBot 地址、代理和网络是否可访问。SoutuBot 超时会自动重试一次，连续失败时请稍后再试。

### 文件发送失败

确认 NapCat 正在运行，NapCat HTTP API 端口与“NapCat 地址”一致，并确认 NapCat 有发送群文件和私聊文件的权限。HTTP 请求返回 200 不一定代表 NapCat 业务处理成功，具体原因请查看 MaiBot 和 NapCat 日志。

### 只看到“插件初始化失败”

在 MaiBot 日志中搜索插件 ID `hydrogen-francium.jm_plugin`，查看后面的具体阶段和错误。常见原因是依赖未安装、配置字段类型错误、NapCat 地址格式错误或宿主版本不支持 MaiBot SDK v2。

不要把包含 API Key、代理认证信息或本地路径的完整日志发到公开群聊或 Issue。

## 更新和卸载

更新插件前建议在 WebUI 中备份配置。更新后重启 MaiBot，确认配置仍然正确。插件 ID 保持不变，更新不会把它识别成全新的插件。

卸载插件前，如果使用了自定义下载目录，请先确认是否需要保留其中的下载文件。删除插件不会自动替你删除自定义目录中的用户数据。

## 安全与隐私

- 不要公开 SauceNAO API Key、代理认证信息或任何服务凭据。
- 不要把 `config.toml` 备份、运行日志、下载图片、PDF、ZIP 或临时文件提交到仓库。
- NapCat 和 FlareSolverr 地址应只对可信网络开放。
- 插件只会在你发送命令并完成配置后访问 JMComic、搜图服务和 NapCat，不会在安装阶段自动测试第三方服务。
